# Project 2 - Expense Tracker

## Description

Expense Tracker is a Python console application that allows users to continuously add expenses and calculate the total amount spent.

This project focuses on mathematical operations and accumulators.

---

## Objectives

- Learn accumulators
- Learn mathematical operations
- Learn continuous data entry
- Build menu-driven programs
