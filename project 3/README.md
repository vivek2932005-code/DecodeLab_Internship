# Project 3 - Random Password Generator

## Description

Random Password Generator is a Python console application that generates secure passwords based on the length entered by the user.

This project introduces Python built-in libraries.

---

## Objectives

- Learn module importing
- Learn random module
- Learn string module
- Generate secure passwords
