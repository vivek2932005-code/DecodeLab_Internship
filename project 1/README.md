# Project 1 - To-Do List

## Description

This project is a simple **To-Do List** application built using Python.

Users can:
- Add new tasks
- View all saved tasks
- Exit the program

This project focuses on learning Python Lists, Loops, Functions, and Menu-Driven Programming.

---

##  Objectives

- Learn Python Lists
- Learn `append()`
- Learn `for` loops
- Learn `while` loops
- Understand user input
- Practice function creation

---
